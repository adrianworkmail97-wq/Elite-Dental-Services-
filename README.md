# Elite Dental Services — Website Demo

Premium responsive website concept for Elite Dental Services, Bulawayo.

Upload `index.html`, `style.css`, and `script.js` to the root of a GitHub repository and enable GitHub Pages from `main` / root.

The content is based on the clinic's public site and should be verified with the clinic before production: phone numbers, addresses, hours, services, insurance wording, branding, photos and any marketing claims.

The appointment form is a front-end demo: it opens WhatsApp and does not store patient information or process payments.
